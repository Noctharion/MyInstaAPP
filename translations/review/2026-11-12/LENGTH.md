# 2026-11-12 — length review of the new labels

Companion to [README.md](README.md). Budget: about 1.2 × the English display width (CJK counts double), at least English + 3, for the 525 new or revised entries that are short labels (≤ 28 characters, or ≤ 40 when the context names a chip, button, tab, heading or title). 22,575 values were measured.

## Shortened noticeably (abbreviations)

Abbreviations are kept only where the label sits in a fixed-width chip, tile, card label, chart legend or segment. Where the same text is a settings row title, sheet button, menu row, screen title, heading or screen-reader label, the full wording is used (73 values expanded in es, it, pt-BR, ro, fr, el and pl). Off/On values of settings rows use each catalogue's existing word (51 values in 17 locales).
